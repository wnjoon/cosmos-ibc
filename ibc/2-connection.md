# Connection

- 서로 다른 두 체인간 상태를 검증하고 신뢰를 형성
- 

Light Client를 통한 검증: Connection은 두 블록체인 간의 연결을 설정하는 데 사용됩니다. 이 연결은 상대 블록체인의 Light Client를 통해 상대방 체인의 상태를 검증하는 역할을 합니다. Connection 자체는 데이터를 직접 전송하는 것이 아니라, 두 체인 간의 신뢰를 형성하는데 필요한 검증 과정을 담당합니다.
	•	보안 채널: Connection은 각 체인에 있는 Light Client와 연결되어, 안전하게 상대방 체인의 상태를 검증합니다. 이를 통해 체인 간의 통신이 신뢰할 수 있는 상태에서 이루어질 수 있도록 합니다.
